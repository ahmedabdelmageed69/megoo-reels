# Daily Reel style rules (owner's standing requests)
- Colors: tools/reel_anim.py rotates a soft palette by date automatically; never hardcode a palette in post.json.
- Music: tools/hum.py is a soft, quiet pad that changes key/progression daily (seeded by date). Keep it gentle, never loud.
- Content must feel emotional and real, not just information: open with a relatable pain/moment (a lost photo, a stressful bill, a late-night worry), write each point as a tiny scene (❌ زمان feeling → ✅ دلوقتي relief), speak to "you", cover hook asks a question or names the pain, CTA invites sending it to a specific person. Still exact apps and steps, no invented facts.
- Look: tools/reel_anim.py + tools/build.py pick a different UI style (round / sharp / outline / soft), entry animation, slide transitions and palette per (date, am|pm) automatically. Morning Reels go in reels/<date>/am/, evening in reels/<date>/. Never hardcode a style in post.json.
- Pace: with the voice-over each Reel is ~55-60s max (slide lengths follow the speech); keep the hook in the first 3 seconds and the TOTAL spoken text to about 105 words (cover + 5 points incl. prompts + cta; the calm voice reads ~1.7 words/s), otherwise the voice gets sped up. tools/lint_post.py counts it.
- 8 AM Reel (reels/<date>/am/): same 7 slides and the same ~60s cap, but futuristic neon look (tools/reel_anim.py detects the am/ folder) and a livelier, still-soft arpeggio track (tools/hum.py MUSIC_MODE=am). Its caption.txt is SHORT: 2 lines + 1 question + the standard save/send line, follow line, and EXACTLY 5 hashtags. The topic must differ from the same day's 8 PM Reel.
- Website: always show/write it as a real link, https://megoo.me (video shows a 🌐 link pill; in captions write https://megoo.me before "(اللينك في البايو)"). Instagram does not make caption links clickable, so the bio link is the real one.
- Voice-over: if GEMINI_API_KEY (or GEMINI_API_KEYS) is set, tools/build.py makes a Gemini TTS voice FIRST (tools/voiceover.py): one low, secretive, same-voice take reading ALL slide text; slide lengths and line reveals follow the speech; total Reel must be <= ~60s (speech is sped up to max 1.25x to fit; if still too long, shorten the slide text). Optional "vo" per slide overrides what is spoken.
- NEVER repeat content: before choosing topics run `python3 tools/check_unique.py --list` (every app + action already used) and pick new ideas; tools/build.py runs tools/check_unique.py and REFUSES to build a Reel whose titles, covers or ✅ actions repeat an older Reel (same app + same feature counts as a repeat). Different phrasing of the same trick is still a repeat. Both Reels of the same day must also differ from each other.
- Depth: each Reel = ONE real-life job taken five levels deep (first win → better result → the level most people miss → turn it into action → 💡 pro move or ⚠️ honest limit). Real AI only, never plain phone settings. At least 2 points carry a ready-to-copy "prompt" in Egyptian Arabic, most carry a "path" of exact taps, and post.json lists ≥ 3 "sources". tools/lint_post.py enforces the format and the build refuses a post that fails it.
- Video layout (automatic, from tools/make_reel.py + tools/reel_anim.py): story-style progress segments, slow push-in, number + app tag on top, ❌ as a faded card and ✅ as a solid card, 💡/⚠️ as a dashed card, tap-path chips that pop in with a tap ripple, and a chat box that types the prompt while the voice reads it. Text stays clear of Instagram's right-side buttons. Music ducks under the voice and the mix is loudness-normalised.
