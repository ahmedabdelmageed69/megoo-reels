# Daily Reel style rules (owner's standing requests)
- Colors: tools/reel_anim.py rotates a soft palette by date automatically; never hardcode a palette in post.json.
- Music: every Reel uses the livelier arpeggio track (tools/hum.py MUSIC_MODE=am, the owner's pick) that changes key/progression daily (seeded by date). Keep it gentle under the voice.
- Content must feel emotional and real, not just information: open with a relatable pain/moment (a lost photo, a stressful bill, a late-night worry), tell every Reel as a short STORY of one named everyday hero ("hero" in post.json): cover = hero + problem, each point = a chapter ("🎬" story moment → "👉" what they did with AI), CTA = the happy ending + "وإنت كمان تقدر" + send it to a specific person. The old "❌ زمان / ✅ دلوقتي" format is retired. Still exact apps and steps, no invented facts.
- Look: tools/reel_anim.py + tools/build.py pick a different UI style (round / sharp / outline / soft), entry animation, slide transitions and palette per (date, am|pm) automatically. Morning Reels go in reels/<date>/am/, evening in reels/<date>/. Never hardcode a style in post.json.
- Pace: with the voice-over each Reel is ~55-60s max (slide lengths follow the speech); keep the hook in the first 3 seconds and the TOTAL spoken text to about 105 words (cover + 5 points incl. prompts + cta; the voice reads ~1.7-2 words/s), otherwise the voice gets sped up. tools/lint_post.py counts it.
- 8 AM Reel (reels/<date>/am/): same 7 slides and the same ~60s cap, and the same night-comic look and music as the 8 PM Reel (the daily accent colours still differ between the two). Its caption.txt is SHORT: 2 lines + 1 question + the standard save/send line, follow line, and EXACTLY 5 hashtags. The topic must differ from the same day's 8 PM Reel.
- Website: always show/write it as a real link, https://megoo.me (video shows a 🌐 link pill; in captions write https://megoo.me before "(اللينك في البايو)"). Instagram does not make caption links clickable, so the bio link is the real one.
- Voice-over: if GEMINI_API_KEY (or GEMINI_API_KEYS) is set, tools/build.py makes a Gemini TTS voice FIRST (tools/voiceover.py): one warm, lively storyteller take (clear, normal volume, never whispering) reading ALL slide text; slide lengths and line reveals follow the speech; total Reel must be <= ~60s (speech is sped up to max 1.25x to fit; if still too long, shorten the slide text). Optional "vo" per slide overrides what is spoken.
- NEVER repeat content: before choosing topics run `python3 tools/check_unique.py --list` (every app + action already used) and pick new ideas; tools/build.py runs tools/check_unique.py and REFUSES to build a Reel whose titles, covers, 👉 actions or prompts repeat an older Reel (same app + same feature counts as a repeat). Different phrasing of the same trick is still a repeat. Both Reels of the same day must also differ from each other.
- Depth: each Reel = ONE real-life job taken five levels deep (first win → better result → the level most people miss → turn it into action → 💡 pro move or ⚠️ honest limit). Real AI only, never plain phone settings. At least 2 points carry a ready-to-copy "prompt" in Egyptian Arabic, most carry a "path" of exact taps, and post.json lists ≥ 3 "sources". tools/lint_post.py enforces the format and the build refuses a post that fails it.
- Video layout (automatic, tools/comic.py via tools/make_reel.py + tools/reel_anim.py): COMIC-BOOK UI. Cover = tilted title panel + hero in a spinning starburst + narrator box; each chapter = "الفصل N" stamp + app tag, the title as a shout banner, panel 1 = yellow narrator box (🎬) + coloured action bar (👉) + tap-path stickers + 💡/⚠️ sticky note, panel 2 = the hero (emoji + name) with a speech bubble that types the prompt (or "says", or the 💡/⚠️ line); CTA = "النهاية" panel. Halftone dot background, thick ink borders, offset shadows; accent colours rotate by date. Every Reel (8 AM and 8 PM) uses the NIGHT COMIC look: dark page with coloured halftone, dark panels, light ink lines, neon offset shadows (the owner's pick). Story-style progress segments, slow push-in, text clear of Instagram's right-side buttons. Music ducks under the voice and the mix is loudness-normalised. REEL_UI=classic brings back the old card layout.
